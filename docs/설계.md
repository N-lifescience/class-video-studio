## 순서(스킬이 따를 것)

0. 준비 점검 — ffmpeg, 파이썬, 받아쓰기 모델
1. 영상 받기 — 링크 또는 파일, 나뉜 파일 잇기
2. 조건표 — 요강 읽기 → 확인
3. 받아쓰기 — 컴퓨터 안에서(맥 mlx-whisper, 윈도우 faster-whisper). 조용한 구간·장면 바뀜 찾기
4. 인터뷰 — 이 수업의 핵심, 꼭 남길 장면, 뺄 장면을 사용자에게 묻기
5. 단계 나누기 — 지도안 또는 받아쓴 글 → 확인
6. 구간 고르기 — 콘티 파일 + 미리보기 클립 → 콘티 작업실에서 고침 → 다시 읽기
7. 만들기 — 자르고 잇기, 원래 시각, 단계 꼬리표, 얼굴 가림, (빨리 감기), (해설), 소리 크기
8. 조건 맞추기 — 길이, 확장자, 용량(목표 비트레이트), 해상도
9. 점검 — 조건표 대조, 정지 화면 모음, 얼굴 가림 확인 모음 → 보고

## 시험

- 자동 시험은 ffmpeg로 만든 가짜 영상으로 돈다(학생 영상은 저장소에 넣지 않음).
- 실제 시험은 공모전 원본 수업 영상(`지능정보기술활용 공모전/work/src/…/IMG_4160.MOV`, `work/video/a2o_raw/IMG_137*.MOV`)으로 SSD에서만.
